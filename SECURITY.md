# Security

## Data sensitivity

Conversation exports can contain private, personal, client, account, or credential-bearing material. Use synthetic or sanitized fixtures for public reproduction and debugging.

Do not commit or post private conversation exports, access tokens, credentials, local private paths, or other sensitive source material.

## Reporting

This repository does not currently publish a dedicated private vulnerability-reporting contact or claim a verified private security-reporting channel.

Do **not** disclose secrets, private source data, or exploit details in a public GitHub issue. Public issues may be used only for sanitized, non-sensitive security hardening questions that are safe to discuss openly.

A dedicated private reporting route remains a public-governance gap rather than a capability claimed by this repository.

## Current supported state

The current public release observed during the August 29, 2026 GitHub Estate Reconciliation is `v0.1.0` under the MIT License.

The release has evidence of GitHub-hosted Windows verification covering source tests, wheel construction, fresh-environment installation, CLI fixture execution, schema validation, PASS receipt generation, zero recorded exceptions, and targeted privacy scanning.

That verification is not a claim of penetration testing, security certification, or suitability for processing secrets without appropriate operator controls.
