# Support

## Supported public surface

TKP Conversation Normalizer is a public product component for normalizing supported conversation-export JSON into stable, source-traceable records for Project Foreman and related tools.

For ordinary usage questions and reproducible, non-sensitive defects, use this repository's GitHub Issues.

Please include:

- the input form used, without private conversation content;
- the command or workflow attempted;
- Python and operating-system versions when relevant;
- the observed result and expected result; and
- a minimal sanitized reproduction when possible.

## Do not post

Do not place private conversation exports, access tokens, credentials, local private paths, client data, or other sensitive material in public issues.

Security- or privacy-sensitive handling follows [SECURITY.md](SECURITY.md).

## Current boundary

Support does not imply live account acquisition, decision/authority inference, execution or completion inference, or inclusion of private validation corpora. Those capabilities are outside this repository's current public contract.
